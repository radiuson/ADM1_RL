# 重复评估文件（已从 evcmdp/ 移出）

`evcmdp/` 中有 223 个 (algo, seed, cost_limit) 组合各自存在 2–3 份评估
文件。每组内的 `viol`、`ch4`、`vfa_med` 逐位相同，且 `run_dir` 指向同一
次训练：是同一个检查点被评估多次、写入了不同的哈希文件名，而非独立重复
实验。

保留每组中修改时间最早的一份，其余 241 份移入本目录。`MANIFEST.json`
记录每个被归档文件对应保留哪一份，以及两者的 MD5（已验证全部相同），
可据此完全还原。

## 为何必须移出

按文件计数会把有效样本量虚增约 40 %，从而人为收窄 bootstrap 区间。
去重前后的差异（CMDP 式，对常规控制上包络的甲烷差值中位数）：

| | 区间排除零的族数 |
|---|---|
| 去重前 | 8 / 10 |
| 去重后 | 6 / 10 |

去重后 CPPOPID、FOCOPS、OnCRPO 的 95 % 区间跨零，P3O 为 −23
[−37, −0]。论文引用的所有 evcmdp 数字均以去重后的 563 份为准。

## 未受影响的目录

- `evres/`（517 份）：按 `model` 路径唯一，无重复。同一
  (algo, w, seed) 下的 `models_mem_*`（五步观测堆叠）与 `models_seed_*`
  是不同配置，数值不同，不可合并。
- `evbase/`（113 份）：同一 `name` 覆盖不同 PI 整定，数值不同，不可合并。
