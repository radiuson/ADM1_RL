# 离策略约束族：旧对偶更新设置下的评估（不可用）

本目录的 160 份评估来自 SACLag / SACPID / DDPGLag / TD3Lag 在 OmniSafe
出厂对偶设置下的训练：`lambda_lr` 为 1e-5（在策略对应值 0.035），PID 增益
为 1e-6 / 1e-7（对应 0.1 / 0.01），`warmup_epochs` 为 100 而本研究预算只有
75 个 epoch。在该设置下乘子在整个训练过程中几乎不动，`cost_limit` 对学到
的策略基本没有影响，因此这些数字反映的是缺省参数而不是算法本身。

替换为 `training/train_omnisafe.py` 中对齐尺度后重跑的 160 份（文件名前缀
`corr_`）。差异（越限率中位数，%）：

| 族 | 目标 1 % | 3 % | 5 % | 10 % |
|---|---|---|---|---|
| SACLag  | 0.2 → 0.2 | 0.2 → 0.2 | 0.4 → 1.5 | 12.2 → 4.8 |
| SACPID  | 15.1 → 0.2 | 17.0 → 0.2 | 21.7 → 0.4 | 23.9 → 9.0 |
| DDPGLag | 0.4 → 0.2 | 0.4 → 0.2 | 0.5 → 0.5 | 0.6 → 0.2 |
| TD3Lag  | 0.4 → 0.2 | 0.4 → 0.4 | 3.1 → 1.2 | 1.0 → 0.8 |

SACPID 的改变最大：旧设置下无论限值为何都在 15–24 % 越限，修正后随限值
单调上升。

保留本目录是为了可追溯，不参与任何统计。
